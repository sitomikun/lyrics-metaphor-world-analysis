# 語句の抽出と判定

## 二段階で取りこぼしを減らす

最初に全文を読み、場面・語る声・指示対象の候補を理解する。その後、各区間を順に走査し、比喩候補と世界構成に関わる表現を記録する。主題に合う語だけを採らない。日常的な比喩、句全体の見立て、字義的な描写も見る。重要でない慣用表現はまとめてよいが、見落としと選択的な省略を区別する。

再読では後続の情報が初出の読みを変えるか確認する。変えた場合は根拠箇所を残す。冒頭の仮説に全行を従わせたり、最後の情報を初出時点の話者が既に知っていたことにしたりしない。

## 分析単位と基本義

語彙単位と、それを解釈する文・句・連の範囲を分ける。日本語の形態素一個を自動的に一つの比喩と数えない。複合語、複合動詞、慣用句、複数語表現は、まとまりとしての意味も確認する。同じ表現を結果に都合よく分割し直さない。原文の改行が文法的な文末とは限らない。

基本義は現代の用法における、より具体的・身体的・明確な意味を候補とする。「最頻義」「最古の語源」「漢字を分解した意味」と同一視しない。同じ品詞の意味を優先し、名詞の基本義を動詞へ無説明で移さない。語源だけで現代の比喩性を主張しない。

基本義の出典状態は `辞書等で確認／通常の語義として暫定／確認不能` のように明示できる。曖昧さが中心解釈を左右する場合は信頼できる国語辞典、語彙資源、一次資料を確認する。利用できなければ暫定とし、辞書名や引用を作らない。全語の辞書照合やウェブ検索を機械的に必須にしない。

## 判定の入口

| 候補 | 確認する関係 | 注意 |
|---|---|---|
| 間接的な比喩用法 | 文脈義と基本義が異なり、両者を比較して文脈義を理解できるか | 意味が違うだけでは十分でない。単なる多義・同音異義との区別を考える |
| 直接的な比較・見立て | 複数領域を比較する対象と性質が示されているか | 比較に用いる語が基本義のままでも、比喩関連であり得る |
| 暗示的な継承 | 代名詞、省略、置換が前の比喩的な関係を引き継ぐか | 省略された対象を勝手に確定しない |
| 比較の標識 | 「よう」「みたい」等が何を比較しているか | 推量、例示、同領域の比較の場合もある。標識単独を比喩としない |
| 換喩 | 部分と全体、行為者と道具、場所と集団等の隣接関係が指示を担うか | 比喩と連動する場合もある。両者の関係を説明する |
| 字義的な場面 | 歌詞内で物・行為・場所として成立するか | 非現実的設定だから比喩とは限らない |

これは実務用の判断補助であり、MIPVUの正式な全注釈体系の代替ではない。MIPVUのdirect/indirectを日本語修辞学の直喩/隠喩と完全な一対一対応にしない。

## 別々の軸として記録する

- **言語的関係**：比喩、換喩、字義的用法、複合、保留。
- **表現上の性質**：直喩形式、擬人化、具象化、感覚領域の交差など。必要なものだけ。
- **曲内の働き**：場面の定位、出来事・状態の提示、象徴候補、反復の核、視点や評価の手掛かりなど。
- **説明モデル**：後段の概念対応やブレンド。単語の排他的な種別にしない。

擬人化を認めるには、人に特有な能力・意図・行為を何に与えているか示す。単に無生物が主語であるだけでは足りない。物語内で字義的に動く存在として読む可能性と、表現に擬人的な性質があることは併記できる。

象徴候補には反復、配置、述語、対比などの曲内根拠を挙げる。文化的連想を使うなら曲内根拠と区別し、それだけで「雨＝悲しみ」「光＝希望」等を確定しない。タイトルは本文との関係を検討する資料であり、本文に存在しない像を各区間に補う根拠にはしない。

## 根拠メモの最小仕様

重要な表現ごとに、次を追跡できる形で保存する。短い曲なら作業メモで足り、ファイルや巨大な表を必須にしない。

`E01｜[S1]・区間・曲内L1–2｜最小引用｜判定する語／句の範囲｜文脈義｜基本義と確認状態｜関係と付加的性質｜解釈候補｜根拠の強さ・未確定点`

曲番号・曲内行番号は [報告形式の規則](output-and-examples.md#曲番号と歌詞行番号) に従う。元ファイルの行番号との対応は照合用に保持し、報告のL番号と混ぜない。

根拠の強さは確率ではない。例えば `本文に明示／複数の独立した箇所が支持／局所的に可能／保留` と理由で区別する。語の比喩性、比喩の対象、象徴性、全曲での中心性を一つの確信度にまとめない。

引用は原文と照合し、離れた箇所を連続した引用に見せない。同じ行の複数箇所や同一表現の再出現は位置を区別する。長い引用で分析を代替しない。英語などの混在表現は原文を保持し、直訳・慣用・複数の語義を文脈で比べる。訳を原詞として扱わない。
