# 比喩と世界に対応させたセクション分析

## 境界と機能は別

原タグと各出現のIDを維持し、タグを音楽形式として検証済みとはしない。Aメロ／Bメロ／サビをVerse／Pre-Chorus／Chorusへ自動変換しない。無タグなら改行群、明示的な反復や場面の切替を手掛かりに暫定区間を設け、音楽上の名称を発明しない。

歌詞の意味のまとまりがタグをまたぐことも、タグ内で変わることもある。区間の比較とは別に、対応する文・句の範囲を示す。空の器楽区間は「歌詞なし」とし、緊張、解放、時間の経過を補わない。本文のない区間を、分析し忘れた区間と区別する。

行範囲は曲内の行番号で示し、タグ行を除いて空白行を含める。区間の範囲には次のタグまでの末尾の空白行も含む。例えば2行の歌詞と1行の空白があるVerse 1は `[S1] L1–3`、次のPre-ChorusはL4から始まる。引用の位置は実際に語句がある行を指す。Interludeの本文が空白1行なら「歌詞なし（L22は空白行）」等と記し、番号があることを歌詞の存在と混同しない。本文行がまったくない区間だけは「歌詞なし（L7とL8の間）」「L1の前」「L20の後」等と位置を示す。タグの順序・出現IDは保持し、`S1` は曲番号、`S1-SEC01` 等は区間IDとして区別する。

## 先行する分析を接続する

各区間について以下を記録する。根拠IDが読みにくければ報告では原文の位置と短い引用に置き換える。

`区間・行範囲｜対応するE（語句）・意味領域・W（世界）｜人物・時空・現実性｜維持されるもの／変わるもの｜根拠となる言語操作｜区間の働き`

働きの例は提示、具体化、拡張、対照、保留、問い直し、修正、反復、定着、再解釈、終結、開放された終わり。これは網羅的分類ではない。複数の働きや、根拠不足の保留を認める。セクション名から働きを選ばない。

比較は次の順で必要な関係を拾う。

1. 全区間を順に読み、直前から何を受け取り何を加えるか確認する。
2. 再登場する区間や表現について、固定部分と差分を原文で照合する。
3. 同名区間だけでなく異なるタグの対応表現、繰り返される区間列も比較する。
4. 終端から初出を読み直し、変更された解釈を先行分析へ反映する。

## 言葉による操作を特定する

| 観察 | 問うこと |
|---|---|
| 語の追加・置換・削除 | 何の性質や対象が変わるか。単なる不出現を消滅・克服とみなしていないか |
| 主語・目的語・態 | 誰が働きかけ、誰が受けるか。省略を過剰に補っていないか |
| 時制・アスペクト・指示 | 時点、持続、完了、距離、語る位置が変わるか |
| 否定・条件・願望・可能 | 否定の範囲はどこか。成立した出来事と望まれることを混同していないか |
| 問い・命令・約束・引用 | 誰に何をしている発話か。引用された発言を現在の主張にしていないか |
| 未完の構文・接続詞 | どこまで保留され、どの表現が補うか。後続区間で補われない場合もある |
| 具体的描写と概括 | 同じ対応を凝縮するか、別の評価を導入するか |

「勢いが増す」「サビで解放される」のような音楽的・心理的印象で上表を代替しない。文字数から演奏時間、情報密度、重要度を推定しない。

## 反復の再文脈化

同じ句でも、指示対象、直前の出来事、発話者、肯否、モダリティが変われば読みが変わり得る。変更を主張するなら、初回と再出現の根拠を対にする。文言が変わった事実と、意味が変わったという推論も分ける。

橋渡し区間の後にあるだけで「意味が反転」としない。再確認、継続、保留の持続も結果である。同一フレーズの出現数と、異なる表現で同じ対応が展開されることを区別する。

## 全曲と曲間比較

初期と終端の配置を比べ、変わった次元と固定された次元を明記する。変形、停滞、循環、累積、対置、矛盾の併存、未決着は記述の候補であり、成長物語へまとめる規則ではない。出来事、語り手の評価、読者側の再解釈を区別する。

複数曲は各々の対応と世界を確立してから比較する。同じ語や領域が出ても同じ意味とは限らない。異なる語で同じ関係を構成する場合も拾う。各曲の反例と異なる終わり方を残し、2曲から作家全体の性質へ一般化しない。
